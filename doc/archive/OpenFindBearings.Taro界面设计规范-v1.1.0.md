## 1. 色彩系统

### 1.1 色彩变量

所有颜色通过 CSS 变量定义，SCSS 文件中使用 SCSS 变量（H5 亮/暗运行时切换，RN/MP 编译时硬编码）。

|--------|------|------|------|

| `--bg-card` | `#FFFFFF` | `#1E293B` | 卡片、输入框背景 |
| `--bg-input` | `#F1F5F9` | `#334155` | 输入框背景 |
| `--bg-badge` | `#F1F5F9` | `#334155` | 标签背景 |

| `--border` | `#E2E8F0` | `#334155` | 边框 |
| `--border-light` | `#F1F5F9` | `#1E293B` | 浅分割线 |
| `--primary` | `#2563EB` | `#3B82F6` | 主色 |
| `--primary-light` | `#EFF6FF` | `#1E3A5F` | 主色浅底色 |
| `--primary-hover` | `#1D4ED8` | `#60A5FA` | 主色悬停 |
| `--danger` | `#EF4444` | `#F87171` | 危险/错误 |

| `--success` | `#16A34A` | `#4ADE80` | 成功 |

**快捷入口背景色（三个圆形按钮）：**
- 讲语音：`--gradient-voice` = 蓝/浅蓝渐变（亮）/ `#1E3A5F` 纯色（暗）
- 拍轴承：`--gradient-camera` = 绿/浅绿渐变（亮）/ `#14332A` 纯色（暗）
- 扫条码：`--gradient-scan` = 橙/浅橙渐变（亮）/ `#3B2111` 纯色（暗）

### 1.2 主题切换

| 平台 | 实现方式 | 亮/暗切换 |
|------|----------|-----------|
| H5 | CSS 变量 + `.theme-dark` class | JS 运行时切换 |
| 微信小程序 | CSS 变量 + `.theme-dark` class | JS 运行时切换 |
| Android（RN） | SCSS 变量硬编码 | 不支持（固定暗色） |
| iOS（RN） | SCSS 变量硬编码 | 不支持（固定暗色） |

RN 和 MP 不支持 `linear-gradient()`，渐变色统一用纯色替代。

## 2. 页面结构

### 2.1 底部 TabBar

**微信小程序**：使用原生 tabBar 配置（`app.config.ts`），需要准备 6 个图标文件（81x81px PNG）：
- `static/tabbar/home.png` / `home-active.png`
- `static/tabbar/store.png` / `store-active.png`
- `static/tabbar/user.png` / `user-active.png`

**H5 / RN**：使用自定义浮动底栏组件 `CustomTabBar`（`position: fixed; bottom: 0`）。

```
┌─────────────────────────────────────────────────┐
│                    App 内容                      │
│                                                 │
│                                                 │
├─────────────────────────────────────────────────┤
│   [首页 House]    [入驻 Store]    [我的 User]   │  ← TabBar 48px
└─────────────────────────────────────────────────┘
```

入驻商家 Tab 已认证时：图标变为 48px 圆形，突出 12px，带阴影。

### 2.9 TabBar 样式差异

| 平台 | 实现方式 | 图标 | 安全区适配 |
|------|----------|------|-----------|
| H5 | 自定义浮动组件 | Lucide 组件 | padding-bottom |
| 微信小程序 | 原生 tabBar | 本地 PNG 图标 | 自动 |
| Android（RN） | 自定义浮动组件 | Lucide 组件 | padding-bottom |
| iOS（RN） | 自定义浮动组件 | Lucide 组件 | padding-bottom |

## 3. 组件清单

| 组件 | 路径 | 平台差异 |
|------|------|----------|
| CustomTabBar | `src/components/CustomTabBar/` | MP 用原生 tabBar；H5/RN 用此组件 |
| NavBar | 各页面内联 | 所有平台相同布局 |

---

## 4. 技术约束（平台差异）

| 特性 | H5 | 微信小程序 | RN（Android/iOS） |
|------|-----|-----------|------------------|
| CSS 变量 | 支持 | 支持 | 支持（RN 0.70 StyleSheet） |
| `var()` | 支持 | 支持 | 支持（RN StyleSheet） |
| `linear-gradient` | 支持 | **不支持** | **不支持** |
| `env()` | 支持 | 支持 | **不支持** |
| `transition` | 支持 | 支持 | **不支持** |
| `animation` | 支持 | 部分支持 | **不支持** |
| 数值 font-weight | 支持 | 支持 | **不支持**（仅 400/700） |
| `line-height` 无单位 | 支持 | 支持 | **不支持** |
| TabBar | 自定义组件 | 原生 tabBar（需本地图标） | 自定义组件 |
| `position: fixed` | 支持 | 支持（但有层级限制） | 支持 |

**RN/MP 不支持渐变**：所有 `linear-gradient` 用纯色替代（取渐变第一个色值或语义色）。

## 5. 路由配置

```ts
// src/app.config.ts
export default defineAppConfig({
  pages: [
    'pages/home/index',          // 首页
    'pages/merchant/index',      // 入驻
    'pages/my/index',           // 我的
    'pages/home/search',         // 搜索结果
    'pages/my/settings',        // 设置
    'pages/home/bearingDetail',  // 轴承详情
    'pages/merchant/merchantDetail', // 商家详情
  ],
  window: {
    backgroundTextStyle: 'light',
    navigationBarBackgroundColor: '#ffffff',
    navigationBarTitleText: 'OpenFindBearings',
    navigationBarTextStyle: 'black'
  },
  // 微信小程序原生 tabBar
  tabBar: {
    color: '#64748B',
    selectedColor: '#2563EB',
    backgroundColor: '#ffffff',
    borderStyle: 'black',
    list: [
      { pagePath: 'pages/home/index', text: '首页', iconPath: 'static/tabbar/home.png', selectedIconPath: 'static/tabbar/home-active.png' },
      { pagePath: 'pages/merchant/index', text: '入驻', iconPath: 'static/tabbar/store.png', selectedIconPath: 'static/tabbar/store-active.png' },
      { pagePath: 'pages/my/index', text: '我的', iconPath: 'static/tabbar/user.png', selectedIconPath: 'static/tabbar/user-active.png' },
    ]
  }
})
```
