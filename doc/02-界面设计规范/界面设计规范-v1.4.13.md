## 0. 本版变更摘要（相对 v1.4.12）

- 新增统一商家跳转入口 `utils/merchantNav.openMerchant(merchantId, mode)`：自己名下商户直接进经营工作台（多商户先 `switchMerchant` 切上下文），其他商户进公开主页。搜索商家 Tab、首页商家推荐、商城商家行、型号详情在售商家、寻货详情商户发布行/应答商家行、我关注的商家、浏览历史八处入口统一改走该方法。

## 1. 运行时主题系统

### 1.1 三模式 × 六预设

- 模式：`light` / `dark` / `system`（`stores/theme.ts`，持久化 `app_theme`；system 用 RN `Appearance` 订阅）。
- 预设（`styles/themes.ts`，`hooks/useThemeColor.ts` 持久化 `app_theme_color`）：天空蓝(默认)/翡翠绿/琥珀橙/玫瑰红/紫罗兰/石墨灰，冷暖兼顾。
- **方案①**：深色用固定中性深色彩底，但强调色仍尊重用户预设（取每预设的 `primaryDark` 亮变体）→ 切深色不跳色、不没收用户颜色。

### 1.2 useTheme() 全色板（`hooks/useTheme.ts`）

返回按 `mode × preset` 计算的完整色板，全站 inline 取用：
`bgPage / bgCard / bgInput / bgBadge / textPrimary / textSecondary / textTertiary / textOnPrimary / border / borderLight / primary / primaryText / primaryDeep / primaryLight / danger / success / warning / navBarBg / navBarText / tabBarBg / tabBarBorder / tabBarText / tabBarTextActive / memberGradientFrom / memberGradientTo / shadowColor`。

| Token | 浅色 | 深色 |
|---|---|---|
| bgPage | #F5F7FA | #0F172A |
| bgCard | #FFFFFF | #1E293B |
| bgInput | #F1F5F9 | #334155 |
| textPrimary | #0F172A | #F1F5F9 |
| textSecondary | #475569 | #CBD5E1 |
| textTertiary | #64748B | #94A3B8 |
| textOnPrimary | #FFFFFF | #0B1220 |
| border | #E2E8F0 | #334155 |
| primary | 预设.primary | 预设.primaryDark |
| danger/success/warning | #EF4444/#10B981/#F59E0B | #F87171/#34D399/#FBBF24 |

> 语义色（快捷三钮蓝/绿/橙、分类色）不随主题变。

### 1.3 全局字号（`stores/fontSize.ts` + `hooks/useFontScale.ts`）

- 档位 small0.9 / medium1.0 / large1.15，持久化 `app_font_size`。
- 用法：`const fs = useFs(); <Text className='x' style={{ ...fs(15), color: t.textPrimary }}>`。className 供颜色/字重，inline 供缩放后字号。

### 1.4 为什么 inline（RN 约束）

Taro RN className 文件作用域 + SCSS 编译期常量 → 运行时改色/字号只能 inline 覆盖，无 CSS 变量/封装组件捷径。启动 `app.tsx` 调 `initFontSize()+initTheme()+initThemeColor()` 恢复。

## 2. 度量体系（承 v1.2.0）

dp 直写双开关（`config.rn.postcss`：`scalable:false` + `pxtransform.config.deviceRatio:{750:2}`）→ SCSS `Npx`=RN `N`dp。关键尺寸：NavBar 44/搜索态48/侧栏72、TabBar 56、快捷圆56、搜索框36、卡片圆角12。RN 红线：禁 gap/组合选择器/CSS渐变/fixed/vh/var回退/百分比圆角；Text 字号行高数值。

### 3.1 商家徽章体系（v1.4.1）

| 徽章 | 样式 | 适用 |
|---|---|---|
| 已认证 | 主题色描边标签（`t.primary` 字 + 边框） | `isVerified=true` 且非互联网来源 |
| 未认证 | 灰底标签（`t.bgInput` 底 + `t.textTertiary` 字） | 非互联网来源且 `isVerified=false` |
| 互联网 | 灰色描边标签（`t.border` 边框 + `t.textTertiary` 字，无底色） | `isInternetSource=true`（无账号、未入驻；不再叠加"未认证"） |
| 普通 | 实心石板灰 `#64748B` 白字 | 已入驻、牌级 `Ordinary` |
| 铜牌 / 银牌 / 金牌 | 实心彩牌 `#B87333` / `#8E9AA8` / `#D97706` 白字 | 牌级 Bronze / Silver / Gold |

- 顺序：身份徽章 → 等级徽章 → 状态角标（置顶 / 补货中）。每行最多两枚身份/等级徽章。
- 长名称处理（v1.4.7）：商家名一律单行省略（`flexShrink: 1` + `numberOfLines={1}`），徽章固定宽度不收缩（`flexShrink: 0`），名称行禁止使用 `flexWrap`——RN 的换行容器不会按 `flexShrink` 重新测量文本，会导致截断失效并压住右侧「邀请」按钮。
- 阶梯语义：互联网（只是公开信息）→ 普通（已入驻，无牌级）→ 铜/银/金（认证 + 在售 + 本期成交）。
- 实现：`utils/level.ts` 的 `getMerchantGradeBadge(rank, isInternetSource)` 提供文案与配色；`components/MerchantBadge` 统一渲染（`size` 控制字号、`withIcon` 详情页头部带徽章图标）。
- 数据前提：互联网来源商家在库里同为 `Ordinary(1)`，"互联网"完全由 `isInternetSource` 派生，不改枚举、不动迁移。
- 覆盖位置：搜索"商家"Tab 列表行、型号详情在售商家行、商家详情头部。

### 3.2 批量操作条（v1.4.5）

商品管理页支持多选批量维护，交互对齐主流商家端（千牛 / 抖店 / 京麦）：

| 元素 | 规范 |
|---|---|
| 入口 | 操作栏右侧描边按钮「批量管理」，进入后变「完成」；左侧「添加商品」在多选模式置灰不可点 |
| 行勾选 | 列表每行左侧 18×18 圆角勾选框（选中主题色填充 + 白色对勾），整行可点切换 |
| 底部条 | 挂在 `PageLayout` 的 `footer` 插槽，白底 + 顶部 1px 分隔线；H5/小程序吸底、RN 位于滚动区之外（不用 `position: fixed`） |
| 全选行 | 左「全选 / 取消全选」、中「已选 N 件」、右「完成」 |
| 动作行 | 五等分按钮：上架 / 下架 / 补货 / 改价 / 删除（删除红色字）；未选中任何条目或执行中整体降透明度 |
| 输入面板 | 「改价」展开涨跌幅输入 + 预览 + 取消；「补货」展开到货时间输入（可空）+ 确认 + 取消 |
| 反馈 | 执行前确认弹窗写明影响件数与需重新审核的件数；结果弹窗给成功/跳过件数与跳过原因 |

## 4. 页面

### 4.1 首页（home）
- 普通模式：NavBar 搜索态铺满搜索框；快捷三钮实心圆；搜索历史(本地)；热门搜索；**热门轴承**(横向卡,`/home.hotBearings`)→轴承详情；**推荐商家**(`home.merchants`,含logo)→商家详情。
- 简洁模式：无 NavBar，搜索框+三钮聚簇垂直居中。

### 4.2 搜索结果页（search）
- 顶部 4 Tab：轴承/商家/品牌/类型。
- 轴承/商家走 BFF 搜索；品牌/类型用 `/home` 全量列表前端过滤。
- 轴承→轴承详情；商家→商家详情；品牌/类型→以该名称再搜轴承。

### 4.3 轴承详情（bearingDetail）
- 图片(`<Image>`,无图占位) + 型号/旧型号/英文名/品牌/类型 + 尺寸(d·D·B)/重量/产地。
- 在售商家(`/bearings/{id}/merchants`)→商家详情；替代品(`/bearings/{id}/interchanges`)→对应轴承详情。
- 在售商家行：认证商家带「邀请」入口；互联网来源商家显示来源徽章与公开电话药丸（点击拨号，v1.4.2）。
- 底部动作区（v1.4.2）：主按钮「寻这个型号」通栏（未登录为「登录后寻这个型号」）+ 一行说明；下行三等分为 收藏 / 分享货源 / 纠错，分享用主题色强调引流属性。
- 收藏 / 纠错：登录门槛（未登录提示）；分享不需登录。

### 4.4 商家详情（merchantDetail）
- Logo(`<Image>`,无图占位) + 名称 + 认证标 + 公司名/类型。
- 联系信息四分支（v1.4.2）：自家商户显示「你经营的商家」；互联网来源显示原样号码 + 拨号药丸（无号码回退邮箱）；认证且生效显示「邀请报价后互给」；其余「暂不接收邀约」。
- 地址、在售数、粉丝数；在售轴承(`/merchants/{id}/bearings`)→轴承详情。
- 关注 / 纠错：登录门槛。

### 4.5 我的（my）
- 头像卡（点击进个人信息，登录门槛）+ 会员卡(LinearGradient 主题渐变) + 四宫格 + 无版本行(已移除)。
- 右上铃铛（v1.4.0）：`badge` 未读红点（与 TabBar 角标同源 notification store），点击进消息中心。

### 4.6 设置（settings）
- 外观：首页模式(简洁需登录)/主题色(6预设,登录门槛)/深色模式(浅/深/跟随,ActionSheet)/字体大小(小中大)。
- 消息(推送/广告,标"暂未上线")、隐私(4项→doc页)、通用(音效暂未上线/震动/**启动时自动检查更新开关(v1.4.0,默认开)**/版本)、其他(服务热线/注销[登录])、退出[登录]。
- 开关用主题化 `<Switch>`。

### 4.7 文档页（common/doc）
- `?type=` 取 `src/content/legal.ts`：隐私政策/收集清单/共享清单/隐私管理/用户协议，PIPL 合规全文，可滚动。

### 4.8 商户入驻域（merchant/*，v1.4.0 成体系）
- **商户页（merchant/index）**：未入驻=入驻引导卡；审核中=状态卡（左滑撤回 SwipeCell）；被拒=可编辑重提（左滑删除）；已入驻=商户卡（aspectFit 白底 logo 头像、名称旁金色"已认证"徽标、副标题角色、四按钮同权：商品管理/成员管理或员工列表/信息维护[管理员]/申请认证[未认证管理员]）+ 邀请横幅（待确认员工邀请 接受/拒绝）。
- **入驻申请（merchant/apply）**：三通道（自助/认领/提名）+ 类型选择 + 材料矩阵上传（ImagePicker）+ 全量商户搜索（已入驻/我的/审核中徽标阻断重复新建）+ 编辑模式复用。
- **商品管理（merchant/manage）**：操作栏小按钮（＋添加商品）；添加=搜索选平台型号+价格/库存/起订量/备注；行内编辑、上下架、"审核中"角标与筛选。
- **成员管理/员工列表（merchant/members）**：行=头像+昵称+角色/状态徽标（本人标"我"，邀请行橙色"已邀请"）；点行=底部**详情面板**（头像/昵称/角色/状态/手机号/加入时间，钉钉同款；手机号列表行不显示仅详情可见）；管理员非本人行下追加操作区（设角色/停用/恢复/移除/撤销邀请）；管理员顶部"添加成员"内联表单（手机号/邮箱+角色，发出为待确认邀请）。
- **信息维护（merchant/profile）**：可改=商户名称/联系人/电话/地址/简介/Logo；只读锁定=企业名称、商家类型、信用代码（空可补录一次）；证照材料区（补证换证入口）。

### 4.9 消息中心（notifications，v1.4.0）
- 收件箱列表（未读点/单条已读跳转/全部已读/下拉分页），TabBar 与铃铛角标同源。

### 4.10 商城货源导购（mall，v1.4.3 重述）

- 定位：供给侧货源导购，只出「能联系、能报价」的认证商家在售货源；顶部是轴承币权益兑换入口 + 搜索框 + 排序（综合/价格/热度）+ 筛选面板（品牌/类型/尺寸）。
- 商品卡（两列网格）：单一白面卡（图区与信息区同底色，无接缝）＝ 图片 + 型号（含「补货中」角标）+ 品牌·类型 + 尺寸 + 价格（统一带 ¥）+ 商家行（含「已认证」）+ 操作位。
- 点击分区（互不重叠、不嵌套，规避 RN 点击穿透）：
  - 图片与文字信息区 → 货源详情（型号详情页，看该型号全部商家与报价）；
  - 商家行 → 店铺页；
  - 「联系商家」→ 直接带该商家发起一对一邀请（预填型号/品牌/型号 ID + 仅邀请 + 目标商家），跳发布页补价格与说明；未登录先弹登录确认。
- 空态分三类：接口失败给「重新加载」，有检索条件说「没有匹配的认证商家货源」，无条件说「暂无认证商家货源」并引导去型号详情看参考在售。
- 卡片与列表均在内容流内（RN 无 fixed），触底加载下一页。
