# Taro 跨端适配说明 v1.0.0

## 概述

Taro 项目一套代码编译到多个平台（H5、微信小程序、Android/iOS），各平台存在 API 差异。本文档说明跨端适配策略和平台特定代码处理。

## 变更日志

### v1.0.0 (2026-09-01)

- 初始版本，平台差异、条件编译、存储适配、API 差异。

## 平台差异

| 能力 | H5 | 微信小程序 | Android/iOS (RN) |
|------|-----|-----------|-------------------|
| HTTP 请求 | fetch | Taro.request | fetch |
| 本地存储 | localStorage | Taro.setStorageSync | AsyncStorage |
| Token 读取 | localStorage | Taro.getStorageSync | AsyncStorage |
| 页面路由 | 浏览器 history | 小程序路由栈 | React Navigation |
| 网络状态 | navigator.onLine | Taro.getNetworkType | NetInfo |
| SVG 图标 | 支持 | Data URL (base64) | react-native-svg |
| TabBar 图标 | PNG | PNG | PNG |
| 剪贴板 | navigator.clipboard | Taro.setClipboardData | Clipboard |
| 相机/图片 | input[type=file] | Taro.chooseImage | ImagePicker |

## 条件编译

Taro 使用 `process.env.TARO_ENV` 区分平台：

```typescript
if (process.env.TARO_ENV === 'weapp') {
  // 微信小程序专用代码
}

if (process.env.TARO_ENV === 'h5') {
  // H5 专用代码
}

if (process.env.TARO_ENV === 'rn') {
  // React Native 专用代码
}
```

### 平台检测工具

```typescript
// src/utils/platform.ts
import Taro from '@tarojs/taro'

export function isH5(): boolean {
  return Taro.getEnv() === Taro.ENV_TYPE.WEB
}

export function isWeapp(): boolean {
  return Taro.getEnv() === Taro.ENV_TYPE.WEAPP
}

export function isRN(): boolean {
  return Taro.getEnv() === Taro.ENV_TYPE.RN
}
```

## 存储适配

### Token 存储

```typescript
// src/utils/token.ts
import Taro from '@tarojs/taro'

export function setStorage(key: string, value: string): void {
  Taro.setStorageSync(key, value)
}

export function getStorage(key: string): string | null {
  try {
    return Taro.getStorageSync(key) || null
  } catch {
    return null
  }
}

export function removeStorage(key: string): void {
  Taro.removeStorageSync(key)
}
```

Taro 的 `setStorageSync` / `getStorageSync` 在各平台自动适配：
- H5 → localStorage
- 小程序 → wx.setStorageSync
- RN → AsyncStorage

### Token 安全策略

| Token | 存储方式 | 理由 |
|-------|----------|------|
| access_token | 内存变量（useState/useRef） | 不持久化，防 XSS/泄露 |
| refresh_token | 本地存储 | 持久化用于自动刷新 |
| device_id | 本地存储 | 持久化，登录时绑定 |

## 网络请求适配

### 基础地址

```typescript
function getBaseUrl(): string {
  // H5：同源（相对路径）
  if (Taro.getEnv() === Taro.ENV_TYPE.WEB) return ''
  // 小程序/App：BFF 公网域名
  return process.env.TARO_APP_BFF_BASE_URL || 'https://bff.515813.xyz'
}
```

### 请求头差异

各平台 `Content-Type` 设置方式一致，无需特殊处理。`Authorization` 头通过 `header` 参数传递。

### CORS

- H5：受浏览器 CORS 策略限制，BFF 需配置 `AllowOrigin`
- 小程序：不受 CORS 限制（微信有自己的安全策略）
- RN：不受 CORS 限制

## 图标适配

### lucide-react-taro

在 H5 和小程序端使用 Data URL 渲染 SVG，兼容性好。在 RN 端需切换到 `lucide-react-native`（基于 react-native-svg）。

```typescript
// 未来 RN 适配时的条件导入
let Icon: React.ComponentType<{ size?: number; color?: string }>

if (process.env.TARO_ENV === 'rn') {
  Icon = require('lucide-react-native').Search
} else {
  Icon = require('lucide-react-taro').Search
}
```

### TabBar 图标

TabBar 不支持 SVG，统一使用 PNG 文件。使用 `npx lucide-react-taro-cli` 生成各尺寸 PNG。

## 小程序特殊限制

### 登录方式

微信小程序可使用手机号快捷登录（SMS grant），无需输入密码：

```typescript
// 微信小程序专用登录
if (isWeapp()) {
  // 使用 wx.login 获取 code，后端换 token
  const { code } = await Taro.login()
  // 调用 /mobile/auth/login-sms
}
```

### 分享

小程序原生支持分享，H5 需要 Web Share API：

```typescript
// 小程序：onShareAppMessage
// H5：navigator.share
```

### 包大小

微信小程序主包限制 2MB，需注意：
- 图片使用 CDN 地址而非本地
- 使用按需加载（Taro 动态 import）
- 监控构建产物大小

## 构建命令

| 平台 | 命令 | 产物 |
|------|------|------|
| H5 | `pnpm run build:h5` | dist/ |
| 微信小程序 | `pnpm run build:weapp` | dist/ |
| React Native | `pnpm run build:rn` | / |

本地开发：

```bash
# H5
pnpm run dev:h5

# 微信小程序（需配合微信开发者工具）
pnpm run dev:weapp
```
